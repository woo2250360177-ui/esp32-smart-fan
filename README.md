# TL-C12C 整机联测版 11.0.0-tlc12c

把 src/main.cpp 替换到你的工程；同时复制 lib 文件夹和 platformio.ini 到工程根目录。
所有库已经附带，无需安装未知包。main.cpp 已内嵌算法和网页，不需要自定义头文件。
以后修改网页须同步修改 main.cpp 内的 PAGE；本发布版的单文件 main.cpp 为入口。

接线：IO32 经 1k 电阻接 3904 B，E 接共地，C 接蓝线；黄线接 IO33，同时经 10k 上拉到 3V3。
红线接 12V 正；黑线接 12V 负，负极与 ESP32 GND 共地。12V 正不接 ESP32。
底板 DS->26，K1->27，IRED->14，D1->21，BEEP->25。
先关 12V，USB 上传成功后再开 12V。串口 115200。
热点 ESP32-SmartFan，密码 Fan123456，网页 http://192.168.4.1。

网页选低/中/高档分别是约 30/60/100% 指令。启动有 300ms 助推，输出渐变。
0% 指令不保证电机停转；完全断电需切断 12V。RPM 按每转两脉冲估算，未校准。
网页声光自检只短响一次，不代表报警判定已验证。
遥控器 1=阈值，2=趋势，3=手动，0=0%并结束记录；K1短按循环档位、长按切换自动/手动。
记录期间锁定策略/档位，仍可输出0%；600点RAM记录可导出CSV，断电丢失。
自动模式传感器故障或超温报警时请求全速；手动模式保留明确的输出指令。
本版没有定时、夜间模式、湿度、本地屏幕、转速闭环或已验证的堵转报警。

验证：网页逻辑测试通过；本机编译器 --version 因系统 DLL 重定位错误无法启动，所以未完成固件编译或烧录。
请在自己的 PlatformIO 先 Build 再 Upload；这不是已通过整机验收的版本。
